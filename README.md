# Insight Generation 🚀

A simple React web application for Instagram Business Analytics.

This project is currently under development. Right now, the focus is on building the frontend and user interface before integrating the Instagram API.

---

## 📌 What is this project?

Insight Generation is an analytics dashboard that will allow Instagram Business users to:

* Login with their Instagram account
* View profile information
* Monitor followers and engagement
* View analytics


At the moment, the application uses mock data while the UI is being developed.

## ▶️ Running the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app will run on:

```text
http://localhost:5173
```
